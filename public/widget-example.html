Independent license check

A Printwright license is not published on-chain. Hedera holds only an opaque commitment; the certificate is disclosed by whoever holds it, as the proof bundle pasted into this page. This plain HTML page recomputes that commitment in your browser and compares it against the Hedera testnet mirror. It never calls the Printwright marketplace.

Check your own

Paste the proof_bundle from your delivery response in place of the JSON above, or point the element at a URL that serves it:

<printwright-verify bundle-url="https://…/api/v1/certificates/YOUR-CERT-ID"
  topic-id="0.0.9585069" network="testnet"></printwright-verify>

The mirror host is fixed in the widget and the message URL is derived from the topic id and sequence number in the bundle, so a bundle cannot nominate its own “mirror”; pinning topic-id rejects anything anchored elsewhere. What the ledger proves is that these exact bytes were committed no later than the consensus timestamp — not that what they assert is true.
